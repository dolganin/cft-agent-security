# Локальный демонстрационный магазин

Это намеренно уязвимое учебное приложение для изолированной демонстрации агента. В нём есть SQL-инъекция в поиске и форме входа, чтение чужого заказа и открытый список файлов. Файл `backup.env` содержит только фиктивное значение `demo-placeholder-not-a-real-secret`. Данные и учётные записи вымышлены. Не используйте его с реальными данными и не публикуйте наружу.

Запуском, проверкой и очисткой управляет `python -m app.demo`. Для просмотра браузером Compose публикует приложение только на `127.0.0.1:8090`; обычный анализ использует отдельную временную копию без публикации портов.

Демо-вход в форму: `alice@demo.local` / `alice-demo-2026`. Второй контрольный аккаунт: `bob@demo.local` / `bob-demo-2026`.
