# Метрики одного прогона Juice Shop v20.2.0

Расчёт выполнен по сохранённому полному прогону на commit
`5658473cf8814459bf89000ce373b20ed0b4eb37`. Был **один сопоставимый полный запуск**:
68 записей Semgrep, 67 уникальных ID, 4 confirmed, 64 inconclusive в 68 отчётах,
0 rejected. Время — 33 мин 45 с; Gate FAIL, технических ошибок пайплайна — 0.
Предыдущие пилоты и прерванная диагностическая попытка исключены.

## Эталон и единицы измерения

Для recall взяты все **25 позиций исходного кода**, помеченных авторами Juice Shop
комментарием `vuln-code-snippet vuln-line`, в отслеживаемых Git файлах `server.ts`,
`routes/`, `lib/`, `models/`, `frontend/src/`, `views/`. Исключены unit tests,
Docker-disabled и Miscellaneous challenge labels. Совпадение определяется по пути
и попаданию размеченной строки в диапазон SAST-находки. Это существующая авторская
разметка, а не набор, выбранный из успешных подтверждений. Один сайт кода может
соответствовать нескольким заданиям; количество пройденных заданий не измеряется.
Набор построен после запуска, поэтому это предварительная ретроспективная оценка,
не заранее зарегистрированный benchmark всего Juice Shop.

Для precision отдельно проверены все четыре confirmed по исходнику и сохранённым
наблюдениям. Они соответствуют реальным заявленным условиям: SQL-подстановка в login,
SQL-инъекция в search, открытые каталоги `/ftp` и `/encryptionkeys`. Четвёртая позиция
не входит в авторскую `vuln-line` разметку и поэтому участвует только в precision.
Одно подтверждение основано на исходнике, три включают HTTP-наблюдения. Последующее
ревью выполнено кодинговым ассистентом, без слепой разметки другим человеком.

Отрицательные контроли — три срабатывания `detected-jwt-token` в `.spec.ts`:
`app.guard.spec.ts:46`, `last-login-ip.component.spec.ts:72` и `:78`. Это литералы
unit tests для проверки декодирования и localStorage при подменённых сервисах;
ревью классифицирует их как отрицательные для утечки действующего эксплуатационного
credential. Другие потенциальные проблемы тестируемых компонентов этой меткой не
оцениваются. Все три получили inconclusive.

## Вычисленные значения

| Метрика | Значение | Знаменатель и ограничения |
|---|---:|---|
| Precision подтверждений | **4/4 = 100%** | По последующему ревью четырёх заявленных условий; выборка очень мала. 95% интервал Wilson: **51,0–100%**. Не означает 100% качество агента вообще. |
| Доля ложных подтверждений | **0/4 = 0%** | FP/(TP+FP), дополнение к precision на тех же четырёх случаях. |
| Recall на авторской разметке позиций кода | **3/25 = 12%** | Это recall на описанном наборе исходников, не на всех 116 заданиях Juice Shop. |
| Recall baseline SAST на тех же позициях | **4/25 = 16%** | Свежий Semgrep без фильтра агентных вердиктов. Агентный recall ниже на 4 процентных пункта. Precision всего SAST не размечен. |
| Подтверждение найденных SAST эталонных позиций | **3/4 = 75%** | Условный verification recall среди четырёх размеченных позиций, найденных SAST. |
| Точность окончательного вердикта на scoped-наборе | **3/28 = 10,7%** | 25 положительных позиций + 3 отрицательных fixture-случая. Correct = confirmed для positive, rejected для negative. Inconclusive и отсутствие находки считаются неверным/незавершённым ответом. |
| Ложное подтверждение на отрицательных контролях | **0/3 = 0%** | Положительное решение — только confirmed. **Все три контроля получили inconclusive (100% abstention)**, поэтому это не доказательство способности отвергать ложные сигналы. |
| FPR среди окончательных confirmed/rejected | **Не определяется** | Нет rejected true-negative вердиктов; для этой трёхстатусной системы знаменатель FP+TN среди окончательных решений равен нулю. |
| Покрытие оценкой серьёзности CVSS | **0/67 = 0%** | Все уникальные находки UNASSESSED. Точность серьёзности не измерена; difficulty Juice Shop не преобразовывалась в CVSS. |
| Точность Context Priority | **Нет данных** | Нет независимых меток на той же шкале. Выход скоринга: 59 HIGH и 9 LOW на 68 записях. |
| DAST baseline | **Нет данных для этого эксперимента** | Сопоставимый DAST baseline не выполнялся; старый ZAP-пилот не включён. |
| MTTR | **Нет данных** | Временных меток исправлений нет; время анализа не является MTTR. |
| Воспроизводимость полных запусков | **Нет данных** | Есть один полный запуск на текущем входе. Повторные запросы SQL внутри одного действия — это контроль проверки, не повтор всего эксперимента. |

Достоверные различия между наборами: 4 подтверждения используются в precision,
но только 3 из них принадлежат 25 авторским позициям для recall. Поэтому делить
4 на 25 нельзя. Эти исходники содержат только положительные метки; отрицательные
fixture-контроли оценены отдельно после запуска. Из 25 положительных позиций 21
не обнаружена SAST, одна обнаружена, но получила inconclusive, три confirmed.
