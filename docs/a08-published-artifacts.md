# Опубликованные данные A08

Данные опубликованы по прямому запросу пользователя, отдельно от автоматического
коммита исходников. Глобальное исключение `artifacts/` в `.gitignore` сохранено:
включены только перечисленные ниже каталоги и файлы.

## Что доступно после git pull

- `artifacts/a08-handoff-2026-10-13/artifacts/a06-series/`: переданные три A06 runs,
  scorecard, aggregate, preflight и история первоначального неуспешного preflight.
- `artifacts/a08-handoff-2026-10-13/artifacts/a07-series/`: config/lock, один
  завершенный run, три невалидные попытки, Evidence, audit, traces, telemetry,
  manifests, seals и исходные scorecard. Каталог `pytest-tmp` не нужен для
  воспроизведения и не опубликован.
- `artifacts/a08-final-2026-10-13-v3/`: итоговый расчет A08, 41-row CSV карты
  случаев, CSV шести внеэталонных наблюдений, agent/baseline scorecard и seal.
- `artifacts/a08-delivery-2026-10-13.zip`: полный пакет передачи, включающий
  отчеты, расчет, код пересчета и неизмененный исходный архив A06/A07.

SHA-256 пакета:
`3f95d32d84a3fbc949165cc98f84bcf8a021e957a6dfc633c63a09d7b05ff65d`.

## Границы комплектности

Это все необходимые **полученные** данные. Три
`a06-series/run-01..03/sast/source.tar` не были переданы и не восстановлены.
Остальные переданные A06 файлы совпадают с seals; полная проверка исходных A06
пакетов не заявляется. A07 seals проверены полностью. Исходные измерения,
эталон и контрольные суммы не переписывались.

Настоящие .env/API-ключи, .venv, Docker images, node_modules, чужие локальные
изменения, промежуточные повторные расчеты и временные тестовые каталоги не
включены напрямую. Неизмененный исходный архив передачи внутри ZIP сохраняет
вспомогательные файлы оператора, включая его небольшой pytest fixture.
Входы содержат данные локального учебного Juice Shop, а не production.
Проверка на секреты выполнена по шаблонам и не является универсальной гарантией.

`artifacts/.gitattributes` отключает text-конвертацию только для опубликованных
данных. Это необходимо, чтобы сохраненные на Windows CRLF-байты в JSON/logs
остались такими же после коммита и checkout на другой платформе. Корневой
`.gitattributes`, связанный замороженным эталоном, не менялся.
Проверка whitespace отключена только для этих неизменяемых данных: CRLF и
исходные пробелы не исправляются ради lint, поскольку входят в seals.

## Проверка после получения

Из корня проекта запустить команду из
[технического приложения A08](a08-technical-appendix-2026-10-13.md), выбрав новый
output (например `artifacts/a08-local-recheck`). Старые результаты не
перезаписывать. Для пересчета нужны только Python-зависимости; API и Docker
не используются. Явный флаг `--allow-missing-a06-source` сохраняет указанную
неполноту, а не ослабляет проверку остальных файлов.
