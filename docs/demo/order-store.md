# Демонстрационный магазин заказов

[Проверка первого запуска и UI](first-run-verification.md).

`demo-target/order-store` — отдельное локальное веб-приложение, чтобы за короткий показ пройти понятный сценарий: обычный сайт → четыре учебные находки разных типов → действия агента → независимые проверки → Evidence и решение CI.

В магазине намеренно оставлены четыре учебные ошибки:

1. Поиск собирает SQL-выражение с пользовательским вводом.
2. Просмотр заказа проверяет вход в аккаунт, но не проверяет владельца заказа.
3. Форма входа включает введённые email и пароль в SQL-запрос без параметров; фиксированная проверка использует только безвредный булев запрос и не извлекает данные.
4. Открытый список файлов показывает `backup.env`, который доступен без входа. В нём только заведомо фиктивное значение; проверка агента читает список имён и не загружает содержимое.

Детерминированные правила SAST находят участки кода. Для четырёх случаев зарегистрированы фиксированные runtime-маршруты. Проверки используют контрольные запросы и два одноразовых тестовых аккаунта; ответы не сохраняют пароли или токены. Вердикт проходит штатные `ActionProposal → Validator → Executor → Evidence`. Одна лишь находка SAST не считается доказанным результатом. Результаты магазина не являются метриками Juice Shop или оценкой полноты агента на произвольных проектах.

## Запуск показа

Полная последовательность с чистой машины: [быстрый запуск](../../README.md#быстрый-запуск).
Установите зависимости с закреплёнными версиями, заполните `NSU_OPENWEBUI_KEY` в `.env`,
затем из корня репозитория выполните:

```bash
python -m app.setup --prepare-demo
python -m app.demo
```

Подготовка проверяет живую модель и Docker, загружает образ исполнителя и сохраняет
его SHA-256 в `.env`. Она не использует старые артефакты, готовую базу или локальный
checkout Juice Shop. Запуск сервера проверяет необходимые инструменты и порты.

Во втором терминале из корня:

```bash
npm --prefix frontend run dev -- --strictPort
```

Откройте `http://127.0.0.1:5173/demo/order-store` и нажмите «Запустить проверку».
Кнопка отчёта доступна и во время работы: в нём видны этапы, действия и Evidence.
Для чата выберите магазин в боковой панели и отправьте запрос на анализ.

Предпросмотр по умолчанию доступен только на `127.0.0.1:8090`. Отдельные установки
получают разные имена Compose-проектов и не удаляют контейнеры друг друга. Можно
задать `--port`, `--preview-port` и `--data-dir`; пример настройки прокси интерфейса
есть в README. Каждая проверка использует временную копию магазина и закрытую
внутреннюю сеть без опубликованных портов. Ctrl+C останавливает предпросмотр сервера.

Если Docker недоступен, образ не подготовлен или порт занят, сначала выполните
`python -m app.setup --check-model` и устраните указанную причину. Не публикуйте
учебный магазин в интернет и не используйте демонстрационные аккаунты для реальных данных.

## Ускоренный анализ

Для этого магазина `app.demo` объединяет наблюдение разведчика со статической находкой до исполнения только при совпадении снимка исходника, файла, семейства и однозначного операторского маршрута, если диапазоны строк пересекаются и соответствуют ровно одной находке сканера. Исходные наблюдения сохраняются в provenance. Неоднозначные места и разные проверки остаются отдельными находками.

Анализ, гипотеза и одношаговый план запрашиваются одним структурированным ответом. Независимые запросы к модели выполняются по два одновременно, каждый со своим клиентом. Результат привязан к контексту, кандидатам, исходнику, сессии и итерации; изменение входов требует нового рассуждения. При некорректном ответе используется обычный адаптер. Узлы LangGraph, проверка параметров валидатором, исполнение и оценка доказательств остаются штатными. Активные проверки магазина выполняются последовательно, включая создание тестовых аккаунтов.

Локальный замер 15 ноября 2026 года: 51,8 с вместо 176,2 с при той же модели Qwen3.8-27B. Число запросов на разведку и рассуждение снизилось с 23 до 6. Оба запуска дали четыре уникальные подтверждённые находки и одну дополнительную неподтверждённую. Это один замер на прогретом Docker; загрузка сервера модели и холодная сборка могут увеличить время. [Сводка сравнения и контрольные суммы](order-store-performance.json) опубликованы вместе с кодом; полные локальные артефакты находятся в `artifacts/presentation-2026-10-08/runs/run-9fb6365c166c4b2ebf50791bc265fe52/`.
