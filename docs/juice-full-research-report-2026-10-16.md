# Juice Shop: общий исследовательский прогон 16 октября 2026

Получено **13 подтвержденных случаев из 27 положительных A04 cases**:
runtime Recall **48,15%**. В предыдущем сохраненном проходе было **11/27 =
40,74%**. Прирост составляет **2 случая, или 7,41 процентного пункта**.

Два новых подтверждения: `JS-AUTHZ-001` (изменение собственного тестового товара
без авторизации) и `JS-AUTHZ-002` (регистрация с повышенной ролью, подтвержденной
независимым чтением после входа). Рост получен благодаря новым фиксированным
протоколам. Все 11 прежних подтверждений сохранены.

Это один общий запуск с Qwen и фиксированными проверками. Исследовательская
очередь остановилась по бюджету; один вопрос получил ошибку провайдера.
Поэтому результат имеет статус **degraded development diagnostic**, а не
приемку полного исследования всех исходников или независимый blind benchmark.

Qwen обрабатывал **26 исследовательских вопросов**, выполнено **182 модельных
вызова**. Всего действий pipeline — **140**: 16 фиксированных проверочных

| Чтение исходников | 76 |

Сохранено 110 canonical candidate findings. У 20 есть наблюдения модели;
13 кандидатов имеют только модельное происхождение. Это количества кандидатов,
а не 20/13 дополнительно доказанных уязвимостей. Покрытие 27 положительных A04
случаев уже обеспечивалось исходной очередью source detectors/SAST.

В общей очереди на завершении 130 вопросов: 40 имеют статус `researched`,
84 — `pending`, 5 — `grouped`, 1 — `failed`. Статус `researched` также учитывает

Одна модельная ошибка у кандидата `model-scout-826c4e906d8db018d4b6`:
`category=network_error`, `diagnostic=provider_response_validation`.
Вопрос и его след сохранены, очередь продолжила работу. Пустой список
`validation_errors` не позволяет приписывать этой ошибке конкретную ошибку
Pydantic-схемы. Итог кампании — `degraded=true`.

На фиксированную проверку было 40 review-записей: 14 confirmed, 2 inconclusive,
24 review_pending. Только первые 16 соответствуют реальным исполнениям.
Source-condition reviews сохранены отдельно и в runtime Recall не добавлены.

## Почему осталось 14 неподтвержденных случаев

Офлайн-диагностика, опирающаяся на повторный replay и неизмененный matcher,
получила 13 случаев без применимого зарегистрированного runtime-протокола
и один случай, требующий отдельной source-property оценки. В число первых
входит недоступная в закрепленном Docker runtime CODE-ветка.

| Случаи | Что еще требуется |
|---|---|
| JS-BIZ-001, JS-BIZ-002 | Проверки количества и купона с независимым чтением состояния |
| JS-CAPTCHA-001 | Фиксированный протокол свойства CAPTCHA и контроль |
| JS-DATA-002 | Согласованный критерий чувствительных данных metrics и проверка disclosure |
| JS-FILE-002, JS-PATH-001 | Собственные файлы/markers, нормализация и проверка containment |
| JS-NOSQL-002 | Изолированные тестовые заказы и независимая проверка selector |
| JS-RATE-001 | Зарегистрированный порог и фиксированный протокол ограничения запросов |
| JS-SSRF-001, JS-XXE-001 | Локальные контролируемые sinks/fixtures и readback |
| JS-XSS-001, JS-XSS-002 | Независимая проверка браузерного эффекта и отрицательный контроль |
| JS-CODE-001 | Учесть отключенную runtime-ветку; отсутствие исполнения не означает безопасный код |
| JS-CRYPTO-001 | Отдельная оценка source property; source proof уже сохранен отдельно |

Продление исследования само по себе не добавляет недостающие независимые
проверочные протоколы. Следующий прирост runtime Recall требует их реализации
и проверки по одному случаю с последующим общим замером.

## Исполнение и целостность

- Подтверждены очистка отдельных проверок и удаление основного контейнера/сети.
- `source_unchanged=true`; исходный закрепленный target не изменился.
- Проверен seal **518 файлов**. Фактические Python-исходники совпали со всеми
  implementation SHA256 из run manifest после завершения.
- Общий HTTP budget charged: **1322/2048**. Canonical reservation total: 1936;
  наблюдаемые canonical exchanges: 1105; charged canonical capacity: 1308;
  исследовательские HTTP exchanges: 14. Резерв и измеренный расход различаются.
- У новых протоколов сохраняется полный резерв 114 на проверку. Модель не
  управляет возвратом квоты, credentials или параметрами фиксированных probes.
- Текущий код: **1474 passed, 30 skipped**, Ruff и smoke `app.main` проходят.
  Отдельная настоящая Docker-приемка двух новых путей прошла до общего запуска.

При подготовке запуска исправлена неправильная вложенность JSON в интерпретаторе
Evidence и добавлено подключение двух протоколов к campaign и offline replay.
Положительные синтетические тесты раньше повторяли неверную форму ответа;
настоящая интеграционная приемка теперь проверяет фактический fixture output.
