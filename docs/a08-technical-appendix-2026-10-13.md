## Область метрик

Primary original detection включает 27 positive и восемь safe случаев.
DEV: 20 positive + 2 safe; HOLDOUT: 7 positive + 6 safe.
Еще два patched и четыре synthetic safe случая находятся в отдельных срезах.
Все 41 случая сохранены в карте; неисполненные контролы не переименованы в rejected.

A04 помечает 21 positive и три original safe случая runtime-eligible.
В этом отчете основная Recall сохраняет все 27 положительных случаев
исходного каталога и не заявляется как отдельная метрика только runtime-eligible
поднабора. CSV содержит eligibility, чтобы не смешивать доступность runtime
с фактической поддержкой инструмента. `agent_capability_support` эталона
не оценен; для ненайденных случаев отсутствие инструмента не установлено.

Precision = правильные доказанные confirmed / все доказанные confirmed среди
размеченных случаев. Recall = правильные доказанные confirmed / все positive
в выбранном срезе. FPR = ложные доказанные confirmed / все safe в выбранном срезе.
Accuracy вердикта = правильные доказанные confirmed/rejected / доказанные
бинарные решения. Нулевой знаменатель дает N/A. Coverage и abstention
обязательно показаны рядом. TN detection не означает runtime rejected.

## Повторный расчет без Docker и API

Из корня репозитория с установленными Python-зависимостями:

```bash
PYTHONDONTWRITEBYTECODE=1 CFT_AGENT_MODE=stub .venv/bin/python -m scripts.a08_finalize \
  --inputs artifacts/a08-handoff-2026-10-13/artifacts \
  --output artifacts/a08-final-2026-10-13-v3 \
  --original-pipeline-root 'C:\Users\User\Documents\GitHub\cft-security-agent\artifacts\a07-series\agent-run-01-retry-01\pipeline' \
  --allow-missing-a06-source
```

Выбрать новый output для каждого повторения: существующие результаты
не перезаписываются. Флаг разрешает только три уже объявленных source.tar;
не позволяет игнорировать другие повреждения и не означает полной проверки seal.
Windows-root явно сопоставляется только для чтения reports-index. Пути с `..`,
другим drive или другим исходным корнем отклоняются; basename guessing отсутствует.

Выход: summary.json с версией расчета и SHA-256 кода, 41-row CSV карты потерь,
CSV шести внеэталонных находок, четыре agent scorecard, 18 baseline scorecard
и seal нового расчета. Исходные logs/Evidence не включаются в Git автоматически.
